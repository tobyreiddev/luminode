# Wordmark font

`PlusJakartaSans-latin.woff2` is the latin subset of the Plus Jakarta Sans
variable font (weight axis 200–800), served by Google Fonts and vendored here
so the Luminode wordmark renders identically offline and inside the Tauri
webview, whose content security policy only allows same-origin assets.

- Family: Plus Jakarta Sans, by Tokotype
- Licence: SIL Open Font License 1.1 — https://openfontlicense.org
- Source: https://fonts.google.com/specimen/Plus+Jakarta+Sans

Only the wordmark uses it. Application UI text stays on the system font stack.
